# ⏰ ناقوس

**آلارمی که ولت نمی‌کنه.**

ناقوس یه برنامه‌ی آلارم برای اندرویده که یه کار رو متفاوت انجام می‌ده: اگه سر وقت داری با گوشی اسکرول می‌کنی یا بازی می‌کنی، فقط زنگ نمی‌زنه؛ **گوشی رو قفل می‌کنه تا برگردی سراغ کارت.**

---

## ⚡ سوپر آلارم

آلارمی که برای کار مهمت می‌ذاری، مثلاً «ساعت ۱۸ درس خوندن».

- **گوشی خاموش یا کنار دستته؟** مثل یه آلارم معمولی زنگ می‌زنه.
- **داری با گوشی کار می‌کنی؟** همه‌ی برنامه‌ها بسته می‌شن و یه صفحه‌ی تمام‌صفحه با شمارش معکوس روی گوشی میاد. تا پایان مدت (پیش‌فرض ۱۰ دقیقه، قابل تنظیم از ۵ تا ۳۰) نمی‌تونی با گوشی کاری بکنی.
- اسم کاری که تعیین کردی (مثلاً «درس خوندن») وسط صفحه‌ی قفل نمایش داده می‌شه.
- برای ایمنی، تماس ورودی صفحه‌ی قفل رو کنار می‌زنه و دکمه‌ی **تماس اضطراری** (۲ ثانیه نگه داشتن) همیشه هست.

## ✨ امکانات

- آلارم با ساعت و تاریخ **اختیاری** (مثل ساعت سامسونگ: اگه فقط ساعت بدی، نزدیک‌ترین ساعت آینده زنگ می‌زنه)
- تکرار هفتگی، برچسب، غفلت (Snooze)
- آلارم‌ها خاموش می‌شن و پاک نمی‌شن؛ هر وقت خواستی دوباره روشنشون کن
- صدای دلخواه (زنگ‌های گوشی یا فایل از حافظه)، تنظیم بلندی صدا، لرزش، بلند شدن تدریجی صدا
- نوار شناور بالای صفحه وقتی گوشی روشنه، و آلارم تمام‌صفحه وقتی گوشی خاموشه
- تایمر و کرنومتر (با دور)
- چهار تم: نیمه‌شب، شراره، شفق و سپیده (تم روشن)
- کاملاً فارسی

## 📥 دانلود و نصب

1. از بخش **[Releases](../../releases)** آخرین فایل `app-debug.apk` رو دانلود کنید.
2. فایل رو باز کنید. اندروید ازتون می‌خواد نصب از این منبع رو اجازه بدید («نصب از منابع ناشناس»).
3. برنامه رو باز کنید و اجازه‌های اولیه رو بدید.

**نیازمندی:** اندروید ۸ (API 26) یا بالاتر.

## 🔐 اجازه‌ها؛ چرا لازمه؟

| اجازه | دلیل |
|---|---|
| اعلان‌ها | نمایش و کنترل آلارم |
| Alarms & reminders | زنگ زدن دقیق، سر همون دقیقه |
| Appear on top | نوار شناور آلارم روی برنامه‌ها |
| آلارم تمام‌صفحه | روشن کردن گوشی و پر کردن صفحه وقتی خاموشه |
| Accessibility *(اختیاری، ولی لازمه‌ی سوپر آلارمه)* | بستن برنامه‌ها و قفل صفحه |
| بدون محدودیت باتری *(اختیاری)* | جلوگیری از بسته شدن ناقوس توسط سیستم |

ناقوس به اینترنت دسترسی نداره و هیچ داده‌ای جمع نمی‌کنه. همه‌چیز فقط روی گوشی خودتون می‌مونه.

> **اگه گزینه‌ی Accessibility خاکستری بود:** تنظیمات ← برنامه‌ها ← ناقوس ← ⋮ (سه‌نقطه‌ی بالا) ← **Allow restricted settings**، بعد دوباره امتحان کنید. این برای همه‌ی برنامه‌هایی که از خارج Play Store نصب می‌شن لازمه.

## ⚠️ چیزهایی که باید بدونید

- ناقوس در مرحله‌ی **تست** است (نسخه‌ی ۰.۲). ممکنه باگ داشته باشه.
- روش بستن برنامه‌ها روی برند و نسخه‌های مختلف گوشی کمی فرق می‌کنه. اگه روی گوشی شما درست کار نکرد، گزارش بدید.
- «بستن تب‌های مرورگر» ممکن نیست؛ فقط خود برنامه‌ها بسته می‌شن.
- دکمه‌ی پاور همیشه کار می‌کنه و سیستم اجازه‌ی قفل کردنش رو به هیچ برنامه‌ای نمی‌ده.
- روی بعضی گوشی‌ها (مثل شیائومی و هوآوی) باید «شروع خودکار» و «بدون محدودیت باتری» رو دستی فعال کنید تا آلارم‌ها دقیق زنگ بخورن.
